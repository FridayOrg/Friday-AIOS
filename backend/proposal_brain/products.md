- Description: AI-powered document management system built on Microsoft 365 and SharePoint, running inside the client's own Microsoft 365 tenant.

- Configurable components: search-first interface; guided metadata capture; AI metadata extraction; personalised views; version control; approval routing by department or library; duplicate detection; department-restricted templates.
- Compliance positioning: supports SOX, GDPR, ISO 27001 and HIPAA compliance requirements.

## Sangha AI intranet (employee experience)
- Description: AI-powered SharePoint intranet combining news, HR self-service, an AI assistant and personal dashboards; built on SharePoint Framework inside the client's Microsoft 365 tenant.
- Foundation (required): discovery, information architecture, global navigation, design system, brand-aligned homepage, executive communications, announcements, quick links, permissions model, analytics and admin capability.
- Optional modules: EXP Home; My HR / HR Self-Service (Ask HR: question submission, routing, tracking); Ask Sangha AI assistant (cited answers); Personal Dashboard; Departments Hub; Community Hub; Employee Directory; Recognition; My Onboarding (checklists, 30/60/90-day plan, buddy, resources library).
- Role-based access by design: Microsoft 365 security groups and content targeting give every employee the common experience plus content for their role. Permissions are designed into the information architecture from the start.
- Integrations: Teams, Workday, SAP SuccessFactors, ServiceNow, Viva Engage. One HR system integration is included in My HR; further integrations are add-ons.
- Interactive preview (optional): branded representative homepage and key journeys with sample content, so decision-makers can experience it before signing. No production data or integrations.
- Client pays directly: Microsoft, Azure OpenAI and any third-party licence or consumption costs. SPD's proposal covers design, build and deployment.
