## Standard technical statements
- Platform and tenancy: all content remains in the client's Microsoft 365 tenant. SharePoint remains the system of record, so versioning, retention, audit and eDiscovery stay native Microsoft capabilities. DocVault sits above the libraries as a presentation and workflow layer. No client content is copied to SharePoint Designs infrastructure.
- Front end: SharePoint Framework (SPFx) web parts and application customisers, packaged and deployed through the tenant app catalogue.
- Identity and access: sign-in through Entra ID; runs with the signed-in user's existing SharePoint permissions.
- AI services: retrieval restricted to indexed client content, permission-trimmed at query time, with citations to the source document and outputs logged for audit.
- Environments: build and test in a QA environment; promotion to production through the client's change process.
- Exit: documents remain standard SharePoint files with their metadata and version history.
